# Data quality taxonomy

Six categories. A value belongs to exactly one. Never mixed silently,
never inferred from context — every row in `data_catalogue.csv` states
its category explicitly in the `quality` column.

| Category | Definition | Example in this project |
|---|---|---|
| **Real measured** | Directly recorded by a physical metering system (SCADA, AMR) | Elering SCADA generation/consumption readings |
| **Planned** | A schedule/forecast produced by a market participant, not a physical measurement | Elering's "planned" balancing-schedule figures (available since 2010, alongside "actual") |
| **Statistical** | Compiled/aggregated by a national statistics office from returns, surveys or administrative sources | Statistics Estonia's KE21 table (note: since 2023, its hydro/wind/solar columns are themselves sourced from Elering — so from 2023 onward those specific columns are Real measured at origin, Statistical only in the sense of being republished/aggregated by Statistics Estonia) |
| **Derived** | Calculated from other values in this project using a stated formula, with no independent measurement of its own | `domestic_generation_mwh` in the Level 1 balance CSVs (computed as demand + losses − imports so the balance identity closes exactly) |
| **Estimated** | A number inferred through reasoning, extrapolation, or unofficial approximation, where no formula is authoritative | Andorra's import-share-based generation figures; the 42%-imports figure applied to Estonia's 2024 balance (see `data_catalogue.csv` note on year mismatch) |
| **Synthetic** | Generated by this project's own simulator for demonstration or testing, not representing any real-world measurement | Andorra's placeholder available-capacity value in `run_level2_status.py` |

## Relationship to the earlier README language

Earlier project documentation (Level 1/2 READMEs) used a simpler
REAL / DERIVED / ESTIMATED / SYNTHETIC scale. This document supersedes
that for anything Estonia-related going forward, splitting "REAL" into
**Real measured**, **Planned**, and **Statistical** because those three
have meaningfully different reliability and, critically, different
answers to "what happens if this disagrees with another source" (a
disagreement between Real-measured-SCADA and Statistical-KE21 means
something different than a disagreement between two Real-measured
sources). Older files are not being retroactively rewritten just to
relabel them — but any new data added to this project uses this
six-category scale.
