Demand and wind shape are REAL Estonia 2019 hourly data (Elering archive, 8,760 hours). Thermal/import capacities are today's real figures; sliders represent hypothetical capacity investment, not real installed assets. EENS/LOLP/blackout probability come from a single deterministic replay of the real 2019 shape — not a stochastic Monte Carlo estimate (see run_monte_carlo_reliability.py in the main repo for that). Two things worth knowing: (1) this model dispatches thermal before imports, so the baseline scenario shows far lower imports than Estonia's real ~29% import share, which is driven by Nord Pool economics this simplified view doesn't model; (2) EENS can be nonzero even when the RESERVE MARGIN tile looks comfortably positive, because that tile shows the annual average while EENS reflects specific peak hours where capacity actually binds.
